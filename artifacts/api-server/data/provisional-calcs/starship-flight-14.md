# Starship Flight 14 — Starlink V3 provisional mass

**ESTIMATED / provisional.** Last calculated 16 Nov 2026 (America/Los_Angeles).

SpaceX has not published a unit mass for the flown Starlink V3 satellites. We checked the Starlink 2024 Progress Report, the 5 June 2026 BaFin-approved EU prospectus, the IPO roadshow/factsheet, the Q3 2026 earnings release, and the Flight 13/14/15 recaps; none gives kg per satellite. Flight 14 uses the same unit-mass derivation as Flight 15. Only the flight identity changes.

1. **Count (published):** 26 Starlink V3 deployed — SpaceX Flight 14 recap https://www.spacex.com/launches/starship-flight-14 ("the first to deliver meaningful payload to orbit with 26 Starlink V3 satellites"; liftoff Monday, September 28, 2026, 7:48 a.m. CT). Launch Library 2 net is 2026-09-28T12:48:59Z https://ll.thespacedevs.com/2.2.0/launch/7d1afb26-6f9c-429b-9ccf-29012fd1e519/ (Starlink Group 31-1). COSPAR / GCAT launch tag 2026-225. Neither the recap nor the launch record states a mass. The SpaceX recap does not name the ship; public reports identify Ship 41, which is not used in the mass.

2. **Ceiling (derived):** EU prospectus pp. 73 and 110 https://content.spacex.com/cms-assets/FINAL_Documents%20and%20Updates/SpaceX%20-%20EU%20Prospectus%20%28Approved%20by%20Bafin%29%20-%20June%205%2C%202026.pdf says Starship V3 "will be able to carry a payload of 100 metric tons" fully reusable and "a single Starship launch will be capable of deploying up to 60 V3 satellites". 100,000 kg / 60 = 1,667 kg per sat, an upper bound if both apply together (dispenser mass would lower it). Corroborating, no mass: Starlink 2024 Progress Report "about 60 Tbps per Starship launch" https://starlink.com/public-files/starlinkProgressReport_2024.pdf ; Starship specs "100+ t" https://www.spacex.com/vehicles/starship/technical-specifications .

3. **Filing envelope (reported):** SpaceX's FCC Gen3 debris-assessment cases of 2,000 kg / 300 m2 and 2,500 kg / 400 m2 (SAT-LOA-20260630-00264 technical attachment pp. 40-41, as read by YFarmX https://yfarmx.com/space/hardware/starlink-gen3/ and summarised by McDowell in Space.com https://www.space.com/space-exploration/satellites/spacex-wants-to-launch-100-000-starlink-satellites-to-orbit ). Primary PDF not re-opened by us; SpaceX does not officially equate "Gen3" with "V3". These are modelling envelopes, not a confirmed flown mass.

4. **Booked figure (editorial):** 1,500 kg per sat — a conservative pick by the planet42069 desk, set below the 1,667 kg prospectus ceiling. Range shown 1,500-2,500 kg (top = upper FCC envelope).

5. **Batch:** 26 x 1,500 = 39,000 kg booked; range 39,000-65,000 kg.

**Tension we don't hide:** 60 x 2,000 kg = 120 t exceeds the 100 t V3 rating, so either the flown V3 is lighter than 2 t, "up to 60" assumes a later Starship, or the FCC numbers are envelopes. That's why we book below the ceiling.

**Not used:** Wikipedia's ~34,100 kg for Flight 13 (cited to a SpaceX recap that states no mass); a Falcon-median batch (~14 t, wrong vehicle and sat class); Starship capacity as if it were this flight's cargo. Flight 13 itself is not booked: it was suborbital by design and its 20 V3s demised about 20 minutes after deploy (https://www.spacex.com/launches/starship-flight-13).
